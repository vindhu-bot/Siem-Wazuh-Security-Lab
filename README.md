# Siem-Wazuh-Security-Lab
Wazuh SIEM lab includes: Custom PowerShell detection , running Atomic Red Team simulations, Windows authentication monitoring, and investigating a simulated Kali Linux attack.

## LAB Overview 

This project showcases a hands on experience in terms of security and monitoring developed with Wazuh running on Ubuntu server, a monitored Windows Server 2022 endpoint with Sysmon installed, Atomic Red Team to recreate attacks, and Kali Linux for security testing purposes.
